## 📥 **Как скачать:**

### **Способ 1: Скачать отдельные файлы**

Я предоставлю вам список всех файлов для скачивания.

**Ключевые файлы с изменениями:**
1. `public/logo.png` — ваш логотип (650 KB)
2. `src/components/WelcomeScreen.tsx` — с вашим логотипом
3. `src/components/StyleGrid.tsx` — фото-карточки
4. `src/config/styles.ts` — 18 стилей с photoUrl
5. `src/index.css` — стили для фото-карточек

### **Способ 2: Использовать Git (если знаете)**

```bash
# Клонировать репозиторий (если есть на GitHub)
git clone https://github.com/your-username/dekor-info-ai-designer.git
cd dekor-info-ai-designer
npm install
```

## 🚀 **После скачивания:**

1. **Распакуйте архив** (если скачали ZIP)
2. **Откройте терминал** в папке проекта
3. **Выполните:**
   ```bash
   npm install
   npm run dev
   ```
4. **Откройте браузер:** `http://localhost:5173`

**Подробная инструкция:** см. `INSTALLATION_GUIDE.md`
